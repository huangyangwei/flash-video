# flash-video — 低延迟直播播放器

一个单人自用的 Web 低延迟直播播放页：粘贴从抖音页面抓取的 `.flv` 拉流地址，以**最小缓冲 + 可调追帧**播放同一条公开直播流，让自己比抖音 Web 播放器的观众快 1~2 秒看到画面。为直播间抢码场景而生。

## 背景

抖音 Web 播放器为保证流畅内置数秒缓冲，且缓冲只涨不缩，观看时画面天然落后。直播流的分发（CDN、编码、TCP 传输）对所有观众是同一条——**延迟差 100% 来自播放器缓冲**。本项目自己实现播放器，把缓冲压到地板，并用追帧逻辑防止缓冲回涨。

实测：缓冲水位常驻 ~0.4s，比抖音 Web 页面快约 1 秒。

## 功能

- **粘贴即播**：贴入 `.flv` 地址即可播放，纯前端，无服务器
- **最小缓冲**：基于 mpegts.js，`enableStashBuffer: false` + `stashInitialSize: 384`
- **追帧引擎**（三旋钮，全部可调、即时生效）：
  - 变速触发阈值：缓冲水位超过阈值自动变速回吐（默认 1000ms）
  - 变速倍率：1.05x ~ 2.0x（默认 1.1x，音频已静音，无变速负担）
  - 跳帧阈值：水位超过阈值直接 seek 到直播边缘（默认 2000ms，可禁用）
- **断流处理**：`.flv` 地址带签名有时效，断流时弹窗提示重新贴入，恢复后从直播边缘开始
- **设置持久化**：追帧配置存 localStorage，刷新保留

## 快速开始

```bash
npm install
npm run dev      # http://localhost:5173
```

## 使用

1. 打开抖音直播间页面，按 F12 → Network → 过滤 `flv`，复制形如
   `https://pull-xxx.douyincdn.com/live/xxx.flv?...` 的拉流地址
2. 贴入本播放页，点"播放"（默认静音）
3. 与其他画面对比延迟；用右下角的 `水位 xxx ms` 观察缓冲状态

> 地址带签名有时效，过期断流后按弹窗提示重新抓取贴入即可。

## 工作原理

```
抖音CDN ──同一份.flv流──> 抖音Web播放器(缓冲~1.5s) ──> 别人
                    └──> 本播放器(缓冲~0.4s + 追帧) ──> 你 ★
```

- 播放核心 [mpegts.js](https://github.com/xqq/mpegts.js)（FLV over HTTP → MSE）
- 水位 = `buffered.end - currentTime`，每 250ms 采样
- 追帧策略：水位超变速阈值 → 倍率回吐（带迟滞防抖动）；超跳帧阈值 → seek 到最新关键帧
- 15s 看门狗：缓冲不增长且断流 → 提示重贴地址
