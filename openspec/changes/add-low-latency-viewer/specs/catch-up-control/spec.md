# catch-up-control — Delta

## Purpose

追帧是本产品区别于普通播放器的核心能力：缓冲水位超出目标时，自动通过变速或跳帧把画面拉回直播边缘。本能力让追帧行为完全由用户配置，以适应不同人对"贴边"与"流畅"的偏好。

## ADDED Requirements

### Requirement: 追帧参数用户可调
系统 SHALL 允许用户配置以下追帧参数，且配置 MUST 在调整后立即生效（无需刷新页面）：

- 追帧总开关（开/关）
- 变速触发阈值：缓冲水位超过多少 ms 启动变速追帧（默认 1000ms）
- 变速倍率：1.05x ~ 2.0x（默认 1.1x）
- 跳帧阈值：缓冲水位超过多少 ms 直切最新关键帧（默认 2000ms，可设为禁用）

#### Scenario: 调整变速倍率立即生效
- **WHEN** 播放过程中用户把变速倍率从 1.1x 改为 1.3x
- **THEN** 后续触发的变速追帧按 1.3x 执行，无需刷新或重启播放

#### Scenario: 关闭追帧
- **WHEN** 用户把追帧总开关关闭
- **THEN** 系统不再执行变速或跳帧，缓冲行为退化为普通最小缓冲播放

### Requirement: 超限跳帧直切直播边缘
当缓冲水位超过跳帧阈值时，系统 SHALL 直接丢弃积压内容并从最新关键帧继续播放（"一跃到最新"），而不是渐进追赶。跳帧阈值设为禁用时 MUST NOT 发生跳帧。

#### Scenario: 水位超过跳帧阈值
- **WHEN** 缓冲水位超过用户设定的跳帧阈值
- **THEN** 播放位置直接跳到最新关键帧，跳转前后画面连续、无声音残留

### Requirement: 变速范围约束
变速倍率 MUST 限制在 1.05x ~ 2.0x 区间内（音频已静音，上限仅受画面可感知快放约束）。超出该区间的"更激进"需求 SHALL 通过降低跳帧阈值实现，而非提高变速倍率。

#### Scenario: 输入超出范围的倍率被约束
- **WHEN** 用户尝试把变速倍率设置为 3.0x
- **THEN** 系统将其约束为 2.0x 并提示合理范围

### Requirement: 音频默认静音
用户不关心直播声音。系统 SHALL 默认静音播放（视频 playbackRate 变速因此不受音频约束）；用户仍可通过播放器控件手动取消静音。

#### Scenario: 默认静音播放
- **WHEN** 用户粘贴地址开始播放
- **THEN** 画面正常播放且无声；用户可手动取消静音
