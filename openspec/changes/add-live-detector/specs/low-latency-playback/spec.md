# low-latency-playback — Delta

## MODIFIED Requirements

### Requirement: 粘贴地址即可播放
系统 SHALL 提供一个输入入口，用户粘贴 `.flv` 拉流地址后即可开始播放对应直播流，无需任何服务器或后端参与。首次连接失败时系统 SHALL 先执行有界自动重试（递增退避，共 3 次），以覆盖"开播瞬间状态已翻、CDN 流未就绪"的场景；重试耗尽仍失败才展示错误提示。自动重试期间 MUST 在页面展示重试进度，MUST NOT 无限循环静默重试。

#### Scenario: 粘贴有效地址
- **WHEN** 用户粘贴一条有效且未过期的 `.flv` 地址并确认
- **THEN** 页面开始播放该直播流画面（音频默认静音，见 catch-up-control）

#### Scenario: 开播瞬间流未就绪
- **WHEN** 粘贴（或深链携带）的地址格式有效，但首次连接失败（CDN 流尚未就绪）
- **THEN** 页面在展示重试进度的情况下按 2s/4s/8s 自动重试连接，任一次成功即正常播放，无需用户干预

#### Scenario: 粘贴无效地址
- **WHEN** 用户粘贴的地址无法建立连接或格式不正确
- **THEN** 页面先按上述规则自动重试，重试耗尽后展示可读的错误提示，且不崩溃、不再继续重试
